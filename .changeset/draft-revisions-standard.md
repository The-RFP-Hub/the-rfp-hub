Draft v1.0.0 revised in place (spec axis unchanged; the package API is what breaks here). Schema: organisation roles swapped (`operatingOrganizations` required and primary, `sponsoringOrganizations` optional), the six type blocks replaced by a required tagged `fundingDetails` union, `networks`/`tags`/`extensions` removed, `eligibility` now free text, `resourceLinks`→`additionalReferences`, `funding`→`fundingInfo`, `socialLinks` now an array of `{platform, url}` entries, `organization.slug` required, `organization.type`→`orgType`, `deadlines[].type`→`deadlineType`, all date-time fields require UTC (trailing `Z`), and every monetary amount is denominated in the single document-wide `fundingInfo.currency` — `bounty.reward` becomes a plain required number, `accelerator.funding` a plain nullable number, `prizes[]` entries become `{track, amount}` and `checkSize` becomes `{min, max}`, their per-type `currency` keys removed. Package exports: generated `Opportunity` reshaped (now carries a real `fundingDetails` discriminated union), `MonetaryAmount` removed, `SocialLinks`→`SocialLink`, `RegistryName` narrowed, `Timestamp`/`FundingDetails` added. Also: `serviceAgreement`, `milestones[]` and `programModel` promoted from provisional to stable (annotation-only); dual CJS/ESM type declarations, declared Node >=18 engine, JSON-LD context de-aliased, conformance suite expanded and renumbered. See ADRs 0004–0005 and the CHANGELOG field-mapping tables.
