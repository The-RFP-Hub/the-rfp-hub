# RFP Hub — whole-site UI QA sweep

Date: 2026-09-16
Base: `https://the-rfp-hub-dashboard-git-brunodmsi-design-expl-karma-devs.vercel.app` (commit f0940ab or later; verified live via the `/directory` meta-description check before the sweep started)
Signed out throughout. No forms submitted, no Apply links clicked, no login attempted.

## Method note

A first screenshot attempt (`page.screenshot()`) failed with `CdpRequestTimeoutError: CDP request timed out: Page.captureScreenshot`, as flagged as a known risk. The rest of the pass was done with DOM geometry instead of screenshots: `document.documentElement.scrollWidth` vs `clientWidth` for page-level horizontal scroll, per-element `getBoundingClientRect()` sweeps for anything whose right edge exceeds the viewport, `naturalWidth` on `<img>` for broken images, computed `overflow-x` on ancestor chains to distinguish intentional scroll strips from real overflow bugs, `innerText`/`innerHTML` snapshots for copy and empty/error states, and CDP `Log`/`Runtime` event capture for console errors. No visual screenshots are included in this report.

Viewports used: 1440×900 (desktop) and 390×844 (phone), via `Emulation.setDeviceMetricsOverride`.

## Ranked top-10 findings across the site

1. **P0 — `/this-route-does-not-exist` (and any unmatched route) renders Next.js's bare default 404, not the app's own design.** No header/footer, no link back into the site, unstyled black-on-white box. Dead end for mistyped URLs. Fix: add `app/not-found.tsx`.
2. **P0 — `/organisations` and `/organisations/anything` do not redirect to `/organizations`.** Confirmed both by `fetch` and by real navigation (`page.url()` stays on the British spelling). Contradicts the memory note that this shipped in PR #78 — either this preview doesn't have that fix, or it regressed.
3. **P0 — `/sitemap.xml` is a valid but completely empty sitemap** (`<urlset>` with zero `<url>` entries). No `/directory`, no listing pages, nothing discoverable via sitemap.
4. **P0 — `/robots.txt` is `Disallow: /`,** blocking all crawling of the entire site, including `/directory`. Needs confirmation this is preview-only and not shared with production config.
5. **P1 — Sign-in gates on 8 of 9 protected routes have no heading element** (`<p class="empty-title">` instead of `<h1>`/`<h2>`), only `/dashboard` uses a real `<h1>`. Inconsistent and worse for screen-reader/landmark navigation.
6. **P2 — Console shows a recurring CSP violation** from `vercel.live/_next-live/feedback/feedback.js` on every page. Almost certainly a Vercel preview-toolbar artifact, but worth confirming it doesn't leak to production.
7. **P2 — `/directory?page=99` summary line is redundant**: shows "page 99 of 4" and then a separate "Page 99 is past the end of this result" message; could be tightened to one clear statement.
8. **P2 — `/how-it-works` rules matrix table on phone (390px) is 535px wide inside a horizontally-scrolling wrapper with no visible scroll affordance.** Functionally fine (page itself doesn't scroll), but easy to miss that the table scrolls at all.
9. No broken images found anywhere in the sweep (checked `naturalWidth` on every `<img>` across all 44 rendered page/width combinations).
10. No page-level horizontal scroll found anywhere in the sweep — every route's `scrollWidth == clientWidth` at both 1440 and 390, aside from the intentional `/` opportunity strip and the intentional `/how-it-works` table wrapper (both already covered above).
